Gambar luar dimuat tanpa referrer (`referrerpolicy="no-referrer"`). Kebijakan privasi menyebut bahwa situs gambar dapat melihat alamat IP pengunjung |

## Tugas

| #   | Tugas                                                                                                                                                                                                                                                                                                                                                                                                                                         | Uji                                                                                                                           |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 1   | **Admin dari CLI.** `pnpm role:grant` tetap menolak admin; baru: `pnpm admin:grant <email>` dan `pnpm admin:revoke <email>` (hanya CLI, tidak pernah lewat web), tercatat di `audit_log`. Migrasi `0011`: `article_revisions`, aksi audit baru (`admin_grant`, `admin_revoke`, `role_approve`, `article_save`, `article_publish`, `article_unpublish`, `article_restore`, `admin_confirm`).                                                   | Integrasi: CLI, hak DB                                                                                                        |
| 2   | **Penjaga admin.** `AdminGuard`: peran admin dibaca dari DB tiap permintaan; sesi admin diam ≤ 2 jam (dicatat terpisah di sesi) dan mutlak ≤ 12 jam sejak masuk. **Konfirmasi sandi** `POST /v1/admin/confirm` membuka jendela 10 menit di sesi; aksi yang mengubah data tanpa jendela itu → `403 reauth_required` (kode galat baru). Lockout dan batas laju akun berlaku.                                                                    | Integrasi: user/analis 403, sesi kedaluwarsa, tanpa konfirmasi 403, sandi salah, lockout                                      |
| 3   | **Pengajuan peran.** Daftar menunggu (email tersamar, alasan, instansi), setujui/tolak dengan catatan (≤ 500). Pengguna diberi kabar di aplikasi (jenis baru `role_decision`) dan email (template `analyst_decision`). Admin tidak bisa memutus pengajuannya sendiri.                                                                                                                                                                         | Integrasi: alur, putusan ganda (409), kabar + email, audit                                                                    |
| 4   | **Pengguna.** Cari dengan **email persis** (tidak ada pencarian awalan, jadi tidak bisa mengenumerasi akun); hasil tersamar + peran + tanggal daftar. Cabut peran Analis. Admin tidak bisa mengubah perannya sendiri atau admin lain.                                                                                                                                                                                                         | Integrasi: cari, cabut, larangan ubah diri/admin                                                                              |

## Di luar lingkup

2FA (TOTP; tabel disiapkan agar bisa ditambah), unggah gambar, hapus artikel permanen, peran granular, adapter PIHPS.

## Selesai bila

`pnpm audit:all` lulus 20/20, simulasi pengguna (admin menyetujui dan menolak, admin menyunting dan menerbitkan, pengguna biasa dan analis ditolak dari `/admin`) lulus, dan tinjauan independen tanpa temuan berat atau sedang yang terbuka.
