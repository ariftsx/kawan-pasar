# Core API v1 — Kontrak Endpoint

Sumber kebenaran tipe: `packages/contracts/src/`. Next.js (BFF) memvalidasi setiap respons dengan skema yang sama (validasi ganda).

## Aturan umum

| Hal             | Aturan                                                                                                                                                                                                          |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Akses           | Hanya internal. Header `x-service-token` wajib untuk `/v1/*` dan `/internal/*`; `/health/*` publik                                                                                                              |
| Rate limit      | 120 permintaan/menit per (kelompok rute, IP klien). Render server dari web (proxy tepercaya **tanpa** `X-Forwarded-For`) memakai ember `internal` 1200/menit (ADR 0005, 0009). Melebihi → `429` + `Retry-After` |
| IP klien        | `X-Forwarded-For` hanya dipercaya dari proxy di `TRUSTED_PROXY_IPS` (kontainer web)                                                                                                                             |
| Tanggal         | `YYYY-MM-DD` (kalender Asia/Jakarta); waktu ISO-8601 dengan offset                                                                                                                                              |
| Harga           | Integer rupiah per kg                                                                                                                                                                                           |
| Perubahan       | Pecahan 4 desimal (`0.0319` = 3,19%)                                                                                                                                                                            |
| Tidak diketahui | `null` (tidak pernah 0)                                                                                                                                                                                         |
| Cache           | Cache-aside Valkey dengan TTL cadangan (harga/prediksi 1 jam, artikel 6 jam) dan invalidasi eksplisit setelah ingest/promosi bundel                                                                             |
| Galat           | `{"error":{"code","message","fields?"}}`; `fields` berisi nama field saja                                                                                                                                       |

Kode galat: `bad_request` (400), `unauthorized` (401), `not_found` (404), `rate_limited` (429), `internal` (500). Pasar atau komoditas yang tidak dikenal → 404 (bukan 400), sehingga pemanggil tidak memperoleh informasi apa pun selain "tidak ada".

## `GET /v1/markets`

Daftar pasar dari katalog (tanpa query DB).

```json
{
  "items": [
    { "code": "PIKJ", "name": "Pasar Kramat Jati", "city": "Jakarta Timur", "status": "available" },
    { "code": "PSEN", "name": "Pasar Senen", "city": "Jakarta Pusat", "status": "coming_soon" }
  ]
}
```

## `GET /v1/markets/:market/prices`

Ringkasan untuk Beranda dan Harga. Maksimal 2 query saat cache kosong.

```json
{
  "market": {
    "code": "PIKJ",
    "name": "Pasar Kramat Jati",
    "city": "Jakarta Timur",
    "status": "available"
  },
  "latestObservedOn": "2026-09-30",
  "items": [
    {
      "code": "cabai-merah-keriting",
      "name": "Cabai merah keriting",
      "unit": "kg",
      "modelCoverage": "covered",
      "dataStatus": "stale",
      "latest": { "observedOn": "2026-09-30", "priceIdr": 63150 },
      "change7d": 0,
      "change30d": 0.4223,
      "sparkline": [{ "observedOn": "2026-08-19", "priceIdr": 44400 }, "… ≤ 30 titik, naik"],
      "forecast7d": { "status": "available", "q50Change": 0.0102, "direction": "up" }
    },
    {
      "code": "cabai-rawit-hijau",
      "name": "Cabai rawit hijau",
      "unit": "kg",
      "modelCoverage": "pending",
      "dataStatus": "no_data",
      "latest": null,
      "change7d": null,
      "change30d": null,
      "sparkline": [],
      "forecast7d": { "status": "pending_coverage", "q50Change": null, "direction": null }
    }
  ],
  "forecastArtifact": {
    "modelName": "demo",
    "modelVersion": "demo-empirical-quantile-v1",
    "dataVersion": "seed-csv-2026-09-30",
    "preprocessVersion": "none",
    "dataCutoff": "2026-09-30T16:59:59.000Z",
    "issuedAt": "2026-11-11T22:21:50.025Z",
    "isDemo": true,
    "ageDays": 1
  }
}
```

| Field                    | Arti                                                                                                                                                                                                                                                                        |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `dataStatus`             | `fresh`; `stale` = lebih dari 2 hari kerja sejak observasi terakhir (FR-04; libur nasional belum diperhitungkan); `no_data` = belum pernah ada observasi                                                                                                                    |
| `change7d` / `change30d` | Terhadap observasi terakhir pada/sebelum (terakhir − 7/30 hari kalender)                                                                                                                                                                                                    |
| `forecast7d.direction`   | `flat` bila \|median\| < 0,5%                                                                                                                                                                                                                                               |
| Pasar `coming_soon`      | `200`, `items: []`, `latestObservedOn: null`                                                                                                                                                                                                                                |
| `forecastArtifact`       | Metadata bundel di balik semua `forecast7d` (Fase 1C), sehingga setiap angka prediksi di ringkasan bisa ditampilkan bersama versinya. `null` tanpa artefak aktif atau bila artefak `hidden` (> 28 hari). `ageDays` dihitung saat entri cache dibuat (TTL ringkasan ≤ 1 jam) |

## `GET /v1/markets/:market/commodities/:commodity/history?range=30d|90d|365d|all`

Default `90d`. Jendela waktu dihitung mundur dari **observasi terakhir**, bukan dari hari ini, karena data bisa terlambat. `all` diringkas menjadi observasi terakhir setiap minggu (`downsampled: true`).

```json
{
  "market": { "…": "…" },
  "commodity": { "code": "bawang-merah", "name": "Bawang merah" },
  "range": "30d",
  "downsampled": false,
  "points": [{ "observedOn": "2026-09-01", "priceIdr": 38210 }]
}
```

## `GET /v1/markets/:market/commodities/:commodity/forecast`

Satu query. Status dihitung ulang setiap permintaan (cache hanya menyimpan baris DB):

| `status`           | Arti                                                       | `horizons`                                                                     |
| ------------------ | ---------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `available`        | Bundel aktif berumur ≤ 8 hari                              | 8 horizon, naik                                                                |
| `expired`          | Umur > 8 hari                                              | Tetap dikirim; UI **wajib** memberi label "kedaluwarsa"                        |
| `hidden`           | Umur > 28 hari                                             | `[]`, `baseDate`/`basePriceIdr` null; `artifact` tetap ada (untuk menjelaskan) |
| `unavailable`      | Tidak ada bundel aktif, atau komoditas tidak ada di bundel | `[]`                                                                           |
| `pending_coverage` | Komoditas di luar cakupan model                            | `[]`, `artifact: null`                                                         |

```json
{
  "market": { "…": "…" },
  "commodity": {
    "code": "cabai-merah-keriting",
    "name": "Cabai merah keriting",
    "modelCoverage": "covered"
  },
  "status": "available",
  "artifact": {
    "modelName": "demo",
    "modelVersion": "demo-empirical-quantile-v1",
    "dataVersion": "seed-csv-2026-09-30",
    "preprocessVersion": "none",
    "dataCutoff": "2026-09-30T16:59:59.000Z",
    "issuedAt": "2026-11-11T19:05:12.000Z",
    "isDemo": true,
    "ageDays": 0
  },
  "baseDate": "2026-09-30",
  "basePriceIdr": 63150,
  "horizons": [
    {
      "horizonDays": 7,
      "targetDate": "2026-10-07",
      "q10Change": -0.1218,
      "q50Change": 0,
      "q90Change": 0.1677,
      "q10PriceIdr": 55460,
      "q50PriceIdr": 63150,
      "q90PriceIdr": 73735,
      "evalStatus": "available"
    }
  ]
}
```

Bundel yang dipilih: bundel aktif **non-demo** terbaru, atau bundel demo bila tidak ada (ADR 0006). `isDemo: true` → UI wajib menampilkan "Data demo".

## `GET /v1/articles?category=` dan `GET /v1/articles/:slug`

Hanya artikel terbit (`published_at` terisi), urut `order`. `category` ∈ `dasar|prediksi|arif-net|keterbatasan` (lainnya → 400). Slug draf, tidak dikenal, atau tidak valid → 404 tanpa memantulkan input. Item berisi `bodyMd` (Markdown mentah; web wajib merender dengan sanitasi whitelist).

## `POST /internal/cache/invalidate`

Body `{"scope": "prices" | "forecasts" | "articles" | "all"}` (strict) → `{"deleted": n}`. Dipanggil ingest dan promosi bundel (CLI bundel memanggilnya lewat port dev 3001). Penghitung rate limit tidak pernah ikut terhapus.

Setelah cache Valkey dihapus, API meminta web merevalidasi tag yang terkait (`WebRevalidator`, ADR 0009). Langkah ini best effort: kegagalan hanya dicatat dan tidak mengubah respons.

| Scope       | Tag Next.js (`cacheTags` di `@kawan-pasar/contracts`)                   |
| ----------- | ----------------------------------------------------------------------- |
| `prices`    | `prices:<pasar>`, `forecast:<pasar>`, `history:<pasar>:<komoditas>`     |
| `forecasts` | `forecast:<pasar>`, `prices:<pasar>` (ringkasan memuat prediksi 7 hari) |
| `articles`  | `articles`                                                              |
| `all`       | `markets`, `articles`, dan semua tag `prices`                           |

## Web: `POST /api/internal/revalidate` (Next.js)

Hanya dari jaringan Docker. Traefik memblokir path ini dari luar. Header `x-revalidate-token` (`WEB_REVALIDATE_TOKEN`, berbeda dari token layanan) dibandingkan secara constant-time. Body `{"tags": string[]}` (1–50 tag, whitelist `parseCacheTag`, maksimal 8 KiB, strict).

| Kondisi                    | Respons                              |
| -------------------------- | ------------------------------------ |
| Sukses                     | 204                                  |
| Token salah atau tidak ada | 401 (respons identik untuk keduanya) |
| Body tidak valid           | 400                                  |
| Body terlalu besar         | 413                                  |

## `GET /health/live`, `GET /health/ready`

Publik. Readiness memeriksa database dan cache (masing-masing ≤ 1,5 detik) dan mengembalikan `503` bila salah satu tidak tersedia.
